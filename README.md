# 💬 Postix — Social Media Platform

> A production-style social media application built with React — featuring post feeds, user profiles, authentication, and full CRUD interactions, designed for a scalable and responsive user experience.

**[→ View Live Demo](https://postix-oxo.vercel.app/)**

---

## 🌟 Why Postix?

Postix isn't a simple CRUD app or a tutorial clone. It's a complete frontend system designed to simulate a real social platform, handling:

- **Dynamic server state** — posts and comments are fetched, cached, and synchronized efficiently using TanStack Query  
- **Full CRUD functionality** — users can create, edit, and delete posts and comments with instant UI updates  
- **Structured form workflows** — authentication and content creation handled with React Hook Form + Zod validation  
- **Scalable architecture** — clean separation of concerns with reusable components and maintainable structure  
- **Smooth UX** — responsive layout and seamless interactions across all pages  

---

## ✨ Features

**Posts & Feed**
- Global feed displaying all posts  
- Post detail pages with full content and comments  
- Create, edit, and delete posts  

**Comments**
- Add and remove comments on posts  
- Real-time UI updates without page reload  

**Authentication**
- Secure login and registration system  
- Protected routes for authenticated users  
- Session-aware UI behavior  

**Profiles**
- User profile pages with personal posts  
- Navigation between users and their content  

**Navigation**
- Multi-page routing using React Router  
- Clean and structured navigation system  

**Forms**
- Authentication and post creation forms  
- Client-side validation using React Hook Form + Zod  
- Clear and accessible error handling  

**UI / UX**
- Fully responsive design across devices  
- Consistent layout and styling with Tailwind CSS

## 🧱 Tech Stack

| Category | Technology |
|---|---|
| Framework | React |
| Styling | Tailwind CSS |
| Data Fetching | TanStack Query |
| HTTP Client | Axios |
| Forms & Validation | React Hook Form + Zod |
| Routing | React Router |
| Deployment | Vercel |

## 🗺️ Pages

| Route | Description |
|---|---|

| /login | User login |
| /register | User registration |
| /profile/:id | User profile |
